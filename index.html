API Quickstart Beispiel

So einfach lässt sich die Bibliothek in dein JavaScript-Projekt einbinden:

app.js 
import { CoolApp } from '@coolapp/core';

// Initialize CoolApp Instance
const app = new CoolApp({
    apiKey: 'your_api_key_here',
    theme: 'auto'
});

// Fetch Software Metrics
async function loadMetrics() {
    const data = await app.metrics.getStats();
    console.log(`Active Sessions: ${data.activeUsers}`);
}

loadMetrics();
